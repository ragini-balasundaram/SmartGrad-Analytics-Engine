# PART 1 - DATA SELECTION

Dataset Name: Student Performance Dataset (Mathematics) 

Source URL: https://archive.ics.uci.edu/dataset/320/student+performance

Number of Rows and Columns
- Rows: 395
- Columns: 33

Target Variable: 
G3 (The final grade of the student, scored on a scale from 0 to 20).

Reason for choosing this dataset:

  I picked the Student Performance dataset as it is a real world situation we can all relate to - how a student's social life, behavior, and background affect their grades. By trying to predict their final grade (G3), I can test out different regression techniques on a multi- feature dataset. 
  Additionally , finding these kinds of patterns is exactly how schools and colleges can use real time data to identify struggling students early and give them extra guidance.
